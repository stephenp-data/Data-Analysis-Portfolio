# Data Cleaning & Wrangling Project

## OBJECTIVE
Clean and standardize messy real-world sales data to ensure accurate reporting
and analysis.

## DATASET
Sample Superstore Dataset  
Source: Kaggle

## CLEANING TASKS
- Normalize inconsistent categories
- Handle missing and invalid values
- Remove duplicate records
- Validate business rules

## OUTCOME
- Reduced data errors
- Improved reliability of sales and profit metrics
- Enabled accurate downstream analysis
