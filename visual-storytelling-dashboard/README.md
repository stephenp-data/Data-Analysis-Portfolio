# Visualization & Storytelling Analysis

## OBJECTIVE
Communicate key business insights through clear, narrative-driven visualizations.

## DATASET
Global Superstore Dataset  
Source: Tableau Public / Kaggle

## FOCUS AREAS
- Revenue trends
- Regional performance
- Profitability analysis

## EXECUTIVE TAKEAWAYS
- Revenue is concentrated in a few key regions
- Some high-growth regions have declining margins, indicating cost issues
